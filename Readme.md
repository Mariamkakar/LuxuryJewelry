LUXURY JEWELRY

Timeless Beauty, Elegant Design
LUXURY JEWELRY is a stylish and responsive jewelry e-commerce website designed to provide customers with a luxurious and user-friendly online shopping experience. The website allows users to explore jewelry collections, manage their profiles, add products to their cart and favorites, and proceed to payment.

Project Overview
The main goal of this project is to create an elegant online jewelry store where customers can browse beautiful jewelry products and manage their shopping activities through a simple and attractive interface.
The website features a luxury-inspired design using elegant gold accents, cream backgrounds, classic typography, and a dark mode option.

Features
* Home Page: Introduces the jewelry brand with an elegant hero section.
* Shop Page: Displays jewelry products and provides product filtering and search functionality.
* About Us Page: Presents information about the brand and includes customer reviews and feedback.
* User Authentication: Includes Login and Sign Up pages.
* Profile Page: Allows users to manage their personal information, addresses, notifications, settings, and orders.
* Shopping Cart: Allows users to manage selected products.
* Favorites / Wishlist: Allows users to save their favorite jewelry products.
* Payment Page: Provides a payment form for entering payment information.
* Shipping & Returns: Explains shipping information and the return policy.
* Contact Page: Provides a way for customers to contact the business.
* FAQ Section: Helps customers find answers to common questions.
* Dark Mode: Allows users to switch between light and dark themes.
* Responsive Design: Designed to provide a convenient experience across different screen sizes.
* Local Storage: Stores selected website data in the browser, such as cart items, favorites, profile information, and theme preferences.

Technologies Used
* HTML5 — Structures the website pages.
* CSS3 — Styles the website and creates the luxury design.
* JavaScript — Adds interactivity and manages website functionality.
* Local Storage — Saves selected data in the browser.
* Google Fonts — Provides elegant typography.
* Font Awesome / Icons — Supports visual icons where used.

How It Works
1. Users open the website and explore the jewelry collections.
2. Users visit the Shop page to browse, search, and filter products.
3. Users can add products to their shopping cart or save them to favorites.
4. Users can log in or create an account to access protected features.
5. Users can visit their Profile page to manage their information and view order-related details.
6. Users can proceed to the Payment page to enter payment information.
7. Users can learn about shipping, returns, and other store policies.

Design and User Experience
The website follows a luxury-inspired visual identity:
* Gold accents for an elegant jewelry-store appearance.
* Cream and neutral backgrounds for a clean interface.
* Cormorant Garamond and Poppins typography.
* Consistent navigation across pages.
* Light and dark theme options.
* Interactive buttons, forms, and notifications.

How to Run the Project
1. Download or clone the project files.
2. Open the project folder in Visual Studio Code.
3. Make sure the HTML, CSS, JavaScript, components, and image paths are correct.
4. Open index.html in a browser, or use the Live Server extension in Visual Studio Code.
5. Navigate through the website using the navigation menu.

Data and Security Notes
This project uses browser Local Storage for selected features. Data stored in Local Storage belongs to the current browser and is not automatically synchronized across devices.
A production-ready e-commerce website should use a secure backend for user authentication, order management, and payment processing. Real card payments should be handled by a trusted payment provider rather than by storing card details in browser storage.
